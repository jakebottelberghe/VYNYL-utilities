# Array Flatting

A Python 3 package project using a `src/` layout.

## Requirements

- Python 3.15.1 or newer

## Set up a development environment

In PowerShell, run:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

## Run tests

```powershell
python -m pytest
```
